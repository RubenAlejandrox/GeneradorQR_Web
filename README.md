# GeneradorQR_Web
Página Web que genera QR estáticos automáticamente

Aplicación web desarrollada por **@RubenAlejandrox** que permite **crear códigos QR personalizados** de tres tipos:  
- **Texto libre**  
- **URL**  
- **Configuraciones de red Wi-Fi**

Los códigos generados pueden **descargarse en formato PNG** y la aplicación funciona totalmente **en el navegador**, sin necesidad de conexión a internet ni backend.

---

## Características principales

- Genera QR de **texto, enlaces o redes Wi-Fi**.  
- **Diseño moderno y adaptable (responsive)** con CSS puro.  
- **Descarga de QR en formato PNG**.  
- No requiere instalación ni dependencias de servidor.  
- **Hecho 100% en HTML, CSS y JavaScript.**  
- Código limpio y estructurado con un estilo profesional.  

---

## Tecnologías utilizadas

| Tipo | Tecnología | Descripción |
|------|-------------|-------------|
| **Lenguaje base** | HTML5 | Estructura principal del proyecto. |
|  | CSS3 | Diseño visual responsivo y moderno. |
|  | JavaScript (Vanilla JS) | Lógica principal del generador y eventos. |
| **Librería** | [QRCode.js](https://github.com/davidshimjs/qrcodejs) | Librería JavaScript ligera para crear códigos QR desde texto. |
| **Fuentes** | [Google Fonts - Roboto](https://fonts.google.com/specimen/Roboto) | Fuente limpia y legible para toda la interfaz. |
| **Hosting opcional** | GitHub Pages / Netlify / Vercel | Permiten alojar la app de forma gratuita y pública. |
